## 🚀 GitHub Pages

Este repositorio está configurado para GitHub Pages desde la raíz (`/`).

### Para desplegar:

1. Crear repo en GitHub
2. Subir el contenido de `nuclear-aima/`
3. En GitHub, ir a Settings → Pages → Source: Deploy from branch `main`, folder `/ (root)`
4. La landing page estará disponible en `https://[usuario].github.io/[repo]/`
